  
USER INPUT

1) User has 2 inputs: RESUME (upload pdf, docx, txt) **REQUIRED** max 2 uploads  
2) User inputs JOB REQUIREMENTS either 1\. upload pdf, docx, txt; or 2\. url; or 3\. paste in box **REQUIRED** max 2 uploads.
   

PROCESS  
The program inserts the RESUME and the JOB REQUIREMENTS in the specified areas of the prompt and then executes the prompt by sending to Gemini.  
The output from the prompt execution are converted to a Word file and emailed to [glenn@sslduck.net](mailto:glenn@sslduck.net)

The prompt output is also filed in the database in best format for AI to read, using “gap-first-name-last-name-areacode-phone” as the file name, in a folder named GAP-USERS.

The purpose of the GAP-USERS folder is to make GAP reports available to AI for interactive voice conversations with users. Consideration should be made for having a brief set of system instructions for the AI to load along with each GAP report whenever a user requests a conversation. The users request to talk with AI will be made either during the resume and job description submission via check box and name field concurrently with submitting their resume and job requirements, or they get a second chance on the success page.

After the user submits the resume and job description a success page should automatically fire, that page must be available to me for editing, including link and graphic insertions, from the admin page.

The success page will hold sales content including a check-box and name field which on submit will connect them with Glo, our super smart, professional but somewhat quirky female spokes-avatar.  This second offer to connect with Glo to be contained in a box at the top of the success page, containing a brief explanation as what to expect, the check box should be defaulted to unchecked, name field and submit button. Conversations to be interactive voice over internet (not phone.)

The rest of the page will be a sales presentation to sell a custom resume service.
